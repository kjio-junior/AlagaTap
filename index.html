Help

Feature Guide

✓ Logging doses

  • Three statuses: Taken, Skipped, or Missed for every dose.
  • Record Doses opens a picker for all today's doses.
  • Tap any pillbox cell to log that specific slot — even past days you forgot.
  • Swipe right on a cell = Taken. Swipe left = Missed.
  • 5-minute cooldown prevents accidental double-taps (doesn't block skips or past dates).
  • Undo appears in the toast for 6 seconds after any change.

💊 Managing medications

  • Add / Edit / Delete via the icons on each Today's Doses card.
  • Refill button (circular arrow) sets inventory back to max in one tap.
  • Custom schedules: any combination of days and slots per medication.
  • Inventory decrements automatically when you log a dose as Taken.

🔔 Reminders

  • Three independent methods: Browser, Email, Sound — each with its own toggle.
  • Reminders fire 3 minutes before each scheduled dose.
  • Overdue reminders repeat every 30 minutes until logged.
  • Email works on any device with an internet connection.
  • Browser notifications require one-time permission. iOS requires adding to Home Screen first.

👥 Caregiver sharing

  • Tap the Caregiver icon in the header to generate a share link.
  • A QR code is included for easy handoff.
  • The link shows schedule, today's status, history, and adherence.
  • Read-only — the caregiver cannot edit, log, or delete anything.

📅 Data & backup

  • Export JSON backs up all your data to a file.
  • Import JSON restores it on a new device or after cache clearing.
  • Add to Calendar exports an .ics file with reminders built in — great for iOS.
  • Streak counter shows consecutive days without a missed dose.

❓ Troubleshooting

  • Reminders not firing? Check that the toggle is ON and a method is configured.
  • iOS browser notifications only work after adding to Home Screen (iOS 16.4+).
  • Use Add to Calendar if you want the most reliable iPhone reminders.
  • Data missing? Try Import — the last Export file can restore everything.
