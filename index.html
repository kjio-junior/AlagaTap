Help

Feature Guide

✓ Logging doses

  • Three statuses: Taken, Skipped, or Missed for every dose.
  • Record Doses opens a picker for all today's doses.
  • Tap any pillbox cell to log that specific slot — even past days you forgot.
  • Swipe right on a cell = Taken. Swipe left = Missed.
  • 5-minute cooldown prevents accidental double-taps.
  • Streak counter tracks consecutive days without a missed dose.
  • Undo appears in the toast for 6 seconds after any change.

💊 Managing medications

  • Add / Edit / Delete via the icons on each Today's Doses card.
  • Custom schedules: any combination of days and slots.
  • Notes: Add instructions like "Take with food" or "Avoid alcohol".
  • Auto-Refill Prediction: The app calculates how many days of pills you have left and warns you when to refill.
  • One-Tap Refill: Hit the circular arrow to instantly reset inventory to max.

🔔 Reminders

  • Three independent methods: Browser, Email, Sound — each with its own toggle.
  • Reminders fire 3 minutes before each scheduled dose.
  • Overdue reminders repeat every 30 minutes until logged.
  • Email works on any device with an internet connection.
  • Browser notifications require one-time permission. iOS requires adding to Home Screen first.

👥 Caregiver sharing & Data

  • Tap the Caregiver icon to generate a read-only link or QR code.
  • The link shows schedule, notes, today's status, and adherence.
  • Print Summary: Generates a clean paper list of all your meds and notes for doctor visits.
  • Export / Import JSON: Backs up your data to a file so you never lose it.
  • Add to Calendar: Exports an .ics file with alarms built in (great for iOS).

⚙️ Settings & Troubleshooting

  • Text Size Slider: Make the font as big or as small as you need.
  • Tagalog / English: Translate the main interface.
  • Reminders not firing? Check that the toggle is ON and a method is configured.
  • iOS browser notifications only work after adding to Home Screen.
  • Use Add to Calendar if you want the most reliable iPhone reminders.
